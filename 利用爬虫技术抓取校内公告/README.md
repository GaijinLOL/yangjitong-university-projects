# 校内公告与新闻数据采集

这个目录整理了两个数据采集练习：校内官网新闻资讯抓取，以及腾讯新闻热点抓取与可视化展示。

## 数据流程

```text
网页加载 → Selenium / XPath 定位 → 标题、链接、摘要、图片和时间字段抽取
       → 清洗与统一字段 → CSV / MongoDB 保存 → Flask 页面展示或后续分析
```

## 技术栈

- Python、Selenium、Requests、lxml、BeautifulSoup
- MongoDB：保存新闻记录和采集时间
- CSV：保存便于复核和分析的结构化结果
- HTML 模板：展示抓取结果

## 重点文件

- `程序设计基础课设文档/源码/crawler.py`：腾讯新闻采集主脚本
- `程序设计基础课设文档/源码/app.py`：本地展示入口
- `程序设计基础大作业文档/crawler2.py`：校内资讯采集脚本
- `程序设计基础课设文档/源码/腾讯新闻爬取结果.csv`：结构化结果样例

## 面试可讨论的问题

1. 如何处理动态加载页面和元素定位失败？
2. 如何设计字段，避免中文字段、缺失链接和重复记录影响后续分析？
3. 为什么同时保留 CSV 和 MongoDB 两种落盘方式？
4. 如何在采集频率、图片下载和网站访问限制之间取平衡？

运行前请根据本机环境安装依赖并确认 Chrome、ChromeDriver 和 MongoDB 配置；目录中的课程报告包含更完整的过程记录。
