## 阅读顺序

1. 先看本页的项目导航，选择一个与岗位最相关的项目。
2. 阅读项目目录中的 README，了解输入、处理步骤和输出。
3. 查看核心脚本和结果文件，再根据说明在本地运行。
4. 面试时重点说明：问题定义、数据质量处理、指标口径、个人负责部分和结果验证方式。

## 运行与敏感配置

- Python 项目优先查看各目录中的 `requirements.txt` 或 `requirements/`。
- 真实 API 密钥、数据库密码和本地 `.env` 文件不应提交到仓库；请复制 `.env.example` 后在本机填写。
- `runtime_cpu/`、`.venv/`、缓存、视频、压缩包等运行或交付文件被 `.gitignore` 排除。
- 公开仓库中的数据仅用于课程、竞赛或演示；涉及个人信息或未授权数据时，请先脱敏并确认公开范围。
