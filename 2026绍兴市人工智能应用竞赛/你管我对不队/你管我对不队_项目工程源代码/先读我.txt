========================================================
 Curtains3 表面缺陷检测 —— 部署包（先读我）
========================================================

一句话：整个文件夹拷到目标机器上，双击 run_cpu.bat 就能跑。
       不装 Python、不联网（CPU 便携环境随包内置）。
       GPU 加速需自行安装 CUDA 依赖（见下）。

--------------------------------------------------------
 1. 先验证环境（30 秒）
--------------------------------------------------------
  在项目目录打开 cmd，执行：

      run_cpu.bat predict.py --selfcheck

  看到「[OK] 自检通过」就说明环境正常。

--------------------------------------------------------
 2. 跑样例图
--------------------------------------------------------
      run_cpu.bat predict.py --source samples --json

  预期（三条核心基线）：
        val_0013.png  检出 7 个 ink（最高约 0.967）
        val_0011.png  检出 8 个 ink（最高约 0.893）
        test_0007.png 检出 7 个 ink（最高约 0.946）

  samples 里还有一张 val_0011_pred.jpg，是画了框的参考结果图，
  用 --source samples 时会被一起处理，忽略即可。

--------------------------------------------------------
 3. 该用哪个启动器
--------------------------------------------------------
  没有 NVIDIA 独显  ->  run_cpu.bat（随包 runtime_cpu，开箱即用）

  有 NVIDIA 独显     ->  先装 CUDA 依赖（需驱动 >= 522.06）：
      pip install -r requirements\requirements-cuda.txt --index-url https://download.pytorch.org/whl/cu118
      然后用 run_cuda.bat（约 3 倍提速）

  用错不会有损坏，只会报「检测不到可用的 NVIDIA GPU」，
  换回 run_cpu.bat 即可。

--------------------------------------------------------
 4. Web 应用
--------------------------------------------------------
  双击 start_web.bat，打开 http://127.0.0.1:8080 。
  支持图片上传检测、实时摄像头、批次评估与 CSV 导出。

--------------------------------------------------------
 5. 怎么接到自己的程序里
--------------------------------------------------------
  看「前端对接文档.md」，里面有：
    - 命令行调用方式
    - Python 模块 import 方式（推荐）
    - 返回值字段含义
    - 黑白相机的接法（重点）
    - 常见问题排查表

  纯 Python 最小示例：
      import sys; sys.path.insert(0, r"<项目根目录>")
      from predict import CurtainsDetector
      det = CurtainsDetector()              # 进程内只建一次
      r = det.predict_frame(gray_frame)     # gray_frame: numpy (H,W) uint8
      for d in r["detections"]:
          print(d["class_name"], d["conf"], d["xyxy"])

--------------------------------------------------------
 6. 现场必看
--------------------------------------------------------
  部署步骤、必查项、已知风险 ->  「部署说明.md」

  特别提醒（重要）：
    * 先确认目标机装了 VC++ 2015-2022 运行库（C:\Windows\System32\msvcp140.dll
      是否存在）。便携包不自带这个文件，缺了会导致 import torch 失败。
      装一次永久有效：https://aka.ms/vs/17/release/vc_redist.x64.exe
    * 本版模型 mAP@50 只有 0.29，且三个类别里只有 ink
      能稳定检出，hole 与 broken_filament 目前检不出。
      如果产线必须检出这两类，这一版模型需要先补数据重训。
    * 相机像素格式要设成 Mono8；若只能出 16bit，
      位深位移量必须现场实测确认。
    * 光照/曝光要与采集训练数据时保持一致。
    * 建议先把整个目录加入杀毒软件白名单。

--------------------------------------------------------
 7. 目录说明
--------------------------------------------------------
  model/best.pt        模型权重（YOLO11n，hole / ink / broken_filament）
  runtime_cpu/         CPU 便携运行环境（约 0.75 GB，随包内置）
  backend/             Web 服务与批次指标计算
  frontend/            Web 前端（上传 / 摄像头 / 批次评估 / CSV 导出）
  predict.py           推理入口（模块 + 命令行）
  run_cpu.bat          用 CPU 便携环境启动
  run_cuda.bat         用 CUDA 依赖启动（需自行安装）
  start_web.bat        Web 应用一键启动
  samples/             灰度样例图 + 参考结果图 val_0011_pred.jpg
  examples/            Python 模块调用示例
  requirements/        依赖清单（CPU / CUDA / 公共）
  dataset/             训练与验证数据集（images + labels + data.yaml）
  tools/               训练、阈值扫描、校验文件生成等工具脚本
  SHA256SUMS.txt       文件校验值
