# Curtains3 缺陷检测 —— 部署说明（接包必读）

> **结论先行**：整个文件夹拷到 Windows 电脑上，双击 `run_cpu.bat` 就能跑。不需要装 Python、不需要联网（CPU 便携环境随包内置）。有 NVIDIA 独显才需要另装 CUDA 依赖（约 3 倍提速，可选）。

---

## 0. 接包 30 秒上手

1. **拷贝**：整个文件夹拷到目标电脑，建议路径全英文（如 `D:\yolo_deploy`），不要放桌面或含中文、空格的深目录。
2. **自检**：双击 `run_cpu.bat predict.py --selfcheck`，看到 `[OK] 自检通过` 即环境正常。
3. **冒烟**：双击 `run_cpu.bat predict.py --source samples --json`，能输出检测结果即部署成功。想用网页界面就双击 `start_web.bat`，浏览器打开 `http://127.0.0.1:8080`。

三步全过 = 部署完成。下面按需查看对应章节，不用通读。

## 2. CPU 部署（默认路径）

### 2.1 第 0 步：确认 VC++ 运行库（最容易翻车的一步）

torch 依赖微软 `MSVCP140.dll`（VC++ 2015-2022 运行库），**便携包不自带这个文件**。干净安装的 Windows 可能没有，一旦缺失 `import torch` 直接失败。

先检查（cmd 里执行）：

```bat
if exist C:\Windows\System32\msvcp140.dll (echo 已安装，可跳过) else (echo 缺失，需要安装 VC++ 运行库)
```

缺失时安装一次（**装一次永久有效**）：
Microsoft Visual C++ 2015-2022 Redistributable (x64)：`https://aka.ms/vs/17/release/vc_redist.x64.exe`

> 未装运行库的典型报错：`ImportError: DLL load failed while importing _C: 找不到指定的模块`，出现在 `[2/5] torch` 这一步，而不是模型加载阶段。

### 2.2 拷贝

整个文件夹拷到目标机器磁盘，例如 `D:\yolo_deploy`。

> 路径建议全 ASCII，不要放桌面或含中文、空格的深目录（部分厂商 SDK、日志工具、杀毒软件会出问题）。

### 2.3 自检

```bat
run_cpu.bat predict.py --selfcheck
```

看到 `[OK] 自检通过` 即通过。失败看第 5 节排查表。

### 2.4 用样例图冒烟

```bat
run_cpu.bat predict.py --source samples --json
```

`samples/` 有 3 张灰度输入图 + 1 张已画框的参考结果图（`val_0011_pred.jpg` 是输出产物，会被一起处理，忽略即可）。三条核心基线：

| 样例图 | 预期检出数 | 最高置信度 |
|---|---|---|
| `val_0013.png` | 7 个，全为 `ink` | 约 0.967 |
| `val_0011.png` | 8 个，全为 `ink` | 约 0.893 |
| `test_0007.png` | 7 个，全为 `ink` | 约 0.946 |

三次结果与开发机逐位一致，可作为现场验收基线。

### 2.5 现场性能确认

```bat
run_cpu.bat predict.py --source samples/val_0013.png --benchmark 30
```

输出 `avg_infer_ms` 与 `fps`。**这个数字才是现场真实节拍依据**，开发机的数字只能参考。

## 3. GPU 加速（可选）

有 NVIDIA 独显且想提速时使用：

1. 确认驱动版本 ≥ 522.06（对应 CUDA 11.8）。
2. 在系统 Python 中安装 CUDA 依赖：

   ```bat
   pip install -r requirements\requirements-cuda.txt --index-url https://download.pytorch.org/whl/cu118
   ```

3. 用 `run_cuda.bat` 替代 `run_cpu.bat`，其余命令不变。

> CUDA 运行时约 4.6 GB，不随包提供。驱动不满足时会报「检测不到可用的 NVIDIA GPU」，直接换回 `run_cpu.bat` 即可，不会损坏任何东西。

## 4. 打包转交给别人（交接必读）

### 4.1 一键打包

在工程根目录执行：

```bat
runtime_cpu\python.exe tools\pack_deploy.py
```

脚本自动排除开发残留（`.git`、`__pycache__`、`runs`、`outputs`、`.ultralytics`、检测结果 CSV、训练数据集 `dataset`），生成干净的 `你管我对不队_部署包.zip`（放在上层目录），并重新生成包内的 `SHA256SUMS.txt`。

常用选项：

| 命令 | 作用 |
|---|---|
| `tools\pack_deploy.py --dry-run` | 只列清单不打包，先看看会包含什么 |
| `tools\pack_deploy.py --with-dataset` | 附带训练数据集（+约 68 MB，对方要重训时才需要） |
| `tools\pack_deploy.py --no-runtime` | 不含便携运行时（对方有 Python 环境时才用，省约 0.75 GB） |

### 4.2 打包保留 / 排除清单

| 类别 | 内容 | 默认 |
|---|---|---|
| 必带 | `predict.py`、`model/`、`runtime_cpu/`、`backend/`、`frontend/`、`config/`、`samples/`、`examples/`、`requirements/`、`tools/`、三个 .bat、全部文档 | 打包 |
| 排除 | `.git/`、`__pycache__/`、`runs/`、`outputs/`、`.ultralytics/`、检测结果 CSV | 排除 |
| 可选 | `dataset/`（训练数据）、`runtime_cpu/`（便携运行时） | 见 4.1 选项 |

### 4.3 交接时让对方做什么

1. 解压 zip 到全英文路径（如 `D:\yolo_deploy`）。
2. 检查 VC++ 运行库（第 2.1 步；或直接跑自检看结果）。
3. 跑 `run_cpu.bat predict.py --selfcheck` 与样例冒烟（第 2.3 / 2.4 步）。
4. 可选：用 `certutil -hashfile model\best.pt SHA256` 与包内 `SHA256SUMS.txt` 核对。

## 5. 常见问题速查

| 现象 | 原因与处理 |
|---|---|
| `找不到便携 Python 环境` | `runtime_cpu/` 没跟 `run_cpu.bat` 放一起，或拷贝时被漏掉；也可安装系统 Python 后重试 |
| `找不到权重文件` | `model/best.pt` 缺失，用 `--weights` 指定实际路径 |
| 输出中文乱码 | 用 `run_cpu.bat` 启动（已设 `chcp 65001` + `PYTHONUTF8=1`）；直接调 python.exe 时需自行设这两个 |
| `ImportError: DLL load failed ... _C` | 目标机缺 VC++ 运行库 `msvcp140.dll`（不是 torch 装错），见 2.1 安装一次 |
| `检测不到可用的 NVIDIA GPU` | 换 `--device cpu`，或装匹配驱动（CUDA 11.8 需 ≥ 522.06） |
| 第一次调用卡几秒 | 正常（模型图构建）。用 `warmup=True` 提前消化 |
| 相机打不开 | 确认相机没被其他程序占用；厂商相机需用其 SDK，不能直接 `cv2.VideoCapture` |
| 检测框很多但都很像误检 | 调高 `conf`（0.4~0.5），或用 `area_px` 过滤过小框 |
| 完全检测不出缺陷 | 见第 7 节「已知风险」——当前模型本身的能力问题，不是集成问题 |
| `import torch` 以「非法指令」崩溃 | 目标机 CPU 不支持 AVX2（部分 Atom / 赛扬小主机），换机器或另想办法 |

## 6. 现场必查项（这几项错了会直接掉精度）

按重要性排序：

1. **相机像素格式**：必须设成 `Mono8`。只能出 16 bit 时见《前端对接文档.md》4.2 节，位深位移量必须现场实测确认。
2. **光照与曝光**：光源、曝光时间、增益要与采集训练数据时保持一致。这是现场精度波动最大的来源。
3. **分辨率**：训练图全部是 512×512。现场分辨率 / 长宽比差异过大（比如整幅 4000×3000 直接喂）会明显掉精度，先按工艺裁切到接近 512×512 的感兴趣区域。
4. **黑白极性**：缺陷在灰度上是偏亮还是偏暗，需与训练数据比对确认。现场成相反（背光 / 正光不同）需业务侧确认是否做反色。
5. **CPU 是否支持 AVX2**：torch 官方 Windows 轮子要求 AVX2。2013 年后主流 Intel/AMD 都有；部分低功耗小主机（Atom / 部分赛扬）可能没有。用 `--selfcheck` 直接验证——能跑到 `[OK] 自检通过` 就没问题。

## 7. 已知风险与模型局限（必读）

### 7.1 当前模型精度偏低，不建议作为产线唯一判据

| 指标 | 数值（最佳轮次 epoch 21） |
|---|---|
| Precision | 0.484 |
| Recall | 0.419 |
| mAP@50 | **0.290** |
| mAP@50-95 | 0.114 |

训练配置 500 轮，第 31 轮因 `patience=10` 早停；训练集仅 108 张。

### 7.2 三类缺陷中只有 `ink` 能稳定检出

验证集 + 测试集共 72 张，**60 张有检出、全部为 `ink`；`hole` 与 `broken_filament` 一次都没检出**。根因是训练标注严重不平衡（ink 占约 80%）。**如果产线必须检出孔洞和断丝，这一版模型满足不了。**

### 7.3 改善路径

1. 补 `hole` / `broken_filament` 样本重训（各类至少几百框）。
2. 现场先用 `ink` 单类试运行，记录真实过检 / 漏检，反哺数据集。
3. 重训后**接口不变**：新权重覆盖 `model/best.pt` 即可，`predict.py` 和前端代码都不用改。

## 8. 日常维护

### 8.1 换模型

新权重覆盖 `model/best.pt`（保持文件名不变），前端零改动。换完跑一次 `run_cpu.bat predict.py --selfcheck` 确认 SHA256 变了、类别名正确。

### 8.2 想瘦身

| 想省掉 | 操作 | 省下 |
|---|---|---|
| CPU 便携环境 | 删 `runtime_cpu/`（删后需系统 Python + requirements） | 约 0.75 GB |
| 训练数据集 | 删 `dataset/` | 约 68 MB |
| 版本历史 | 删 `.git/` | 约 11 MB |

删之前确认现场不再需要对应能力。

### 8.3 重建 / 升级环境

便携环境不带 `pip`。需要装新包时，在有网的机器上按 `requirements/` 清单 `pip download` 出 wheel，解压到 `runtime_cpu/Lib/site-packages/` 即可（wheel 就是 zip，解压即安装）。

### 8.4 杀毒软件

torch / opencv 的 DLL 常被企业杀软误报。首次部署建议把部署目录加入白名单。

### 8.5 不要在运行时里改文件

`runtime_cpu` 是整体交付的，不要往里面手写业务脚本；业务代码放在包根目录或独立目录，用 `run_cpu.bat 你的脚本.py` 启动。

## 11. 已完成的验证记录（附录）

打包前在开发机上做的验证，结论如下：

| 验证项 | 方法 | 结果 |
|---|---|---|
| 权重来源一致 | 资料库 `train14/weights/best.pt` 与本地训练产物对比 SHA256 | **完全一致**（`ef028a42…eb43`） |
| `best.pt` 确为「最优」 | 与 `last.pt` 比对 | SHA256 不同，确认是独立的 best 权重 |
| 便携环境可用 | 逐包 import numpy / cv2 / torch / torchvision / ultralytics / pandas / scipy / matplotlib | 全部通过 |
| 推理结果与训练环境一致 | 三张样例图，两边都强制 `--device cpu` 比较 | **逐位完全一致** |
| 两套运行时结果一致 | CUDA 运行时跑 CPU 与 CPU 运行时跑 CPU，同图比较 | **逐位完全一致** |
| CUDA 路径可用 | `runtime_cuda` 在 RTX 4060 Laptop 上自检 | 识别到 GPU，CUDA 11.8，10.5 ms/帧 |
| GPU 与 CPU 路径差异 | GPU fp16 vs CPU fp32，同图比较 | 检出数量一致，坐标差 < 0.4 px，置信度差 < 0.002 |
| 灰度输入对齐 | 核验训练集 R=G=B，GRAY2BGR 复制后与训练图逐像素相同 | 最大像素差 **0** |

性能实测（512×512 输入，`imgsz=640`）：

| 运行时 | 设备 | 平均耗时 | 折算帧率 |
|---|---|---|---|
| `runtime_cpu`（torch 2.5.0+cpu） | AMD 32 线程 | 约 34 ms/帧 | 约 29 FPS |
| CUDA（torch 2.5.0+cu118，需自行安装） | NVIDIA RTX 4060 Laptop（fp16） | 约 10.5 ms/帧 | 约 95 FPS |
