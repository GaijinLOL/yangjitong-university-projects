三、源码包怎么跑起来
  unzip 源码-salt-time-1.0.0.zip -d salt-time
  cd salt-time
  cp .env.example .env
  # 编辑 .env，把 DB_PASSWORD 改成一串随机字符
  docker compose up -d --build

  起来之后浏览器打开 http://本机IP:18080
  数据库端口不对宿主机开放，只在 salt-time-net 内部通过服务名 db 访问。
