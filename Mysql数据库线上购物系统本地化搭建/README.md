# 线上购物系统数据库设计

这个项目用 MySQL 建立一个线上购物系统的数据模型，覆盖用户、商品、订单、订单明细、商家、收货地址和商品供应商关系。

## 数据库设计要点

- 通过主键、外键表达用户—订单—商品的关系；
- 使用 `OrderDetails` 拆分订单和商品的多对多关系；
- 通过 `ProductSellers` 表示商品与供应商的多对多关系；
- 使用 `utf8mb4` 支持中文数据；
- 使用存储过程和随机数据生成逻辑准备演示数据；
- 使用 ER 图辅助沟通表结构和业务关系。

## 重点文件

- `商城数据库.txt`：建库、建表、约束和示例数据脚本；
- `ER图商品.drawio`、`ER图商品.png`、`ER图商品.svg`：数据模型图；
- `线上购物系统数据库课程设计报告.doc`：设计背景、表结构和过程记录。
