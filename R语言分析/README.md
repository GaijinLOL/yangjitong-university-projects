# R 语言逐步回归分析

这个目录展示从 Word 表格读取数据、清洗数值字段、进行双向逐步回归，到输出模型摘要和诊断图的完整分析流程。

## 分析流程

1. 从 Word 表格提取数据并统一变量名；
2. 清理千位分隔符、空格和非数字字符；
3. 删除缺失行并检查有效样本量；
4. 使用 `MASS::stepAIC` 进行双向逐步回归；
5. 输出模型摘要、方差分析表、可选 VIF 和四联诊断图。

## 文件

- `R Studio work/逐步回归法_R代码.R`：可复现分析脚本；
- `R Studio work/逐步回归_清理后数据.csv`：清洗后的分析数据；
- `R Studio work/逐步回归_结果.txt`：模型结果；
- `R Studio work/逐步回归_诊断图.png`：模型诊断图。

## 运行

在 RStudio 中打开脚本，确保 Word 数据文件位于同一目录；脚本会自动安装缺失的 `officer`、`docxtractr` 和 `MASS` 包，并将结果写入数据文件所在目录。

面试时可以重点说明变量定义、AIC 选择标准、缺失值处理和诊断图如何支持模型解释，而不只展示最终回归系数。
